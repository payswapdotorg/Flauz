   `registerLanguageModelChatProvider` vendor (e.g. anthropic) via

   while absent, the job runs PROBE-ONLY and records the skip.

## Steps (scripted boot + session)

1. Boot with verbose logging (recipe as C-20 §Steps-1).
2. **[driver — WAITING-ON-LANE F]** Open the chat view, send request R1 to the
   flauz participant (own provider, no Copilot entitlement), do not await it.
3. **[driver — WAITING-ON-LANE F]** Open a second chat session in a new editor
   tab, send request R2 (separate context).
4. **[driver — WAITING-ON-LANE F]** Assert both sessions stream concurrently:
   two distinct chat models, interleaved progress parts, no serialization of
   R2 behind R1 (the AHP executing-session cap is 1 executing + 1 idle on the
   FLOOR case — PERF §4.1 — so the canary asserts *context separation and
   queued visibility*, not 2 executing).
5. Idle 10 min (the §3.2 idle-session eviction window), then capture
   `ps -eo pid,ppid,rss,pcpu,args` — feeding the flauz-perf.yml memory job.
